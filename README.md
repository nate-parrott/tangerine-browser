# Tangerine

<img src="icon-256.png" width="96" alt="Tangerine icon">

Tangerine is a small, experimental WebKit-based browser for macOS.

It has the things you'd expect from a browser — tabs, history, downloads, find-in-page, a combined search/address bar — plus a sidebar with swipeable spaces, split view, content blocking, dark mode for pages, and a couple of experiments (a built-in assistant, terminal tabs).

It's a personal project and it's early. Download the latest build from the [Releases page](https://github.com/nate-parrott/tangerine-browser/releases/latest), or visit the [website](https://tangerine.nateparrott.com/).
